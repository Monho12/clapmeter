Анх нээхэд хөтөч **камер** болон **микрофоны** зөвшөөрөл асууна. Хоёуланд нь **Allow** дарна.

## 2. Event-ийн өмнөх бэлтгэл (≈ 10 минут)

1. Laptop-ыг **HDMI-ээр TV-д** холбоод дэлгэцээ **Duplicate** (ижил дэлгэц) горимд тохируулна.
2. Chrome дээр сайтаа нээгээд **F11** дарж бүтэн дэлгэц болгоно.
3. **Laptop-ын байрлалыг тогтооно.** Үзэгчид рүү харсан, бүх оролцогчийн үед хөдөлгөхгүй байх газар тавина. Энэ нь **хамгийн чухал дүрэм**: laptop хөдөлбөл оноо шударга бус болно.
4. **Микийн мэдрэмжийг тааруулна:**
   - 💀-г 5 удаа дарж PIN **1031** оруулна
   - **🎤 МИК ИДЭВХЖҮҮЛЭХ** дарна
   - Танхим чимээгүй үед ~**40–50**, хүмүүс хүчтэй алга ташихад ~**95–110** гарахаар **МЭДРЭМЖ** гулсуурыг тохируулна
   - Хамгийн чанга алга ташилт ч 120-д хүрэхгүй байх нь зөв. 120-д тулбал гулсуурыг багасгана.
5. **Шалгах:** найзуудаараа алга ташуулж туршилтын нэг хүн бүртгэн хэмжиж үзнэ. Дараа нь тохиргооноос **БҮГДИЙГ УСТГАХ** дарж цэвэрлэнэ.
6. TV-ийн дууг дунд түвшинд тохируулна. 3-2-1 үед дохиоллын дуу гарна.

## 3. Шоуны явц

### ① Финалистуудыг бүртгэх (тайзан дээр, TV-ээр шууд)
Нүүр хуудсанд **+ ФИНАЛИСТ БҮРТГЭХ** дарна. Тэгээд:

1. Ангилал сонгоно (🎩 Эрэгтэй / 👠 Эмэгтэй)
2. **Нэрийг** бичнэ. Костюм/дүрийг хүсвэл бичнэ.
3. Шүүлтүүр сонгоно: 🔎 MUGSHOT · 🟢 ШӨНИЙН ХАРАА · 🔴 ДУЛААНЫ КАМЕР · 📼 VHS · ⚫ НУАР
4. **📸 ЗУРАГ АВАХ** дарахад 3-2-1 тоолоод зураг авна. Таалагдахгүй бол **↺ ДАХИН АВАХ**.
5. **💾 ХАДГАЛАХ** дарна.

> 💡 Нэрээ **зураг авахаас өмнө** бичээрэй. Mugshot самбар дээр нэр зурагт шингэж үлдэнэ.

### ② Эрэгтэй 3-ыг хэмжих
1. Эрэгтэй баганын **▶ ХЭМЖИЛТ ЭХЛҮҮЛЭХ** дарна.
2. Анх удаа бол **🎤 МИК ИДЭВХЖҮҮЛЭХ** дарна.
3. Хөтлөгч: *"Сэжигтэн №1-д алга ташилтаа өгөөрэй!"* гэж хэлнэ.
4. **SPACE** дарна. 3-2-1 тоолж "👏 АЛГА ТАШ!" гарна. Дараа нь **5 секунд хэмжинэ**, энэ үед ямар ч дуу гарахгүй.
5. Оноо гарсны дараа **ENTER** дарвал дараагийн оролцогч руу шилжинэ.

### ③ Эрэгтэйн ялагчдыг зарлах
Гурав дахь хүний дараа **ENTER** дарвал (эсвэл нүүр хуудсанд **🏆 ЯЛАГЧДЫГ ЗАРЛАХ** дарвал) зарлах дэлгэц гарна. **SPACE** дарах бүрт:
- 🥁 бөмбөрийн дуу → **3-р байр** нээгдэнэ
- 🥁 → **2-р байр**
- 🥁🥁 (илүү урт) → **1-р байр** + фанфар + хулуу/сүнсний бороо 🎃👻

### ④ Эмэгтэй 3-д ②, ③ алхмыг давтана.

### ⑤ Тэргүүлэгчид
**🏆 ТЭРГҮҮЛЭГЧИД** дарвал хоёр ангиллын эцсийн жагсаалт гарна. Хараахан зарлагдаагүй ангиллын оноо харагдахгүй (🔒), тиймээс spoiler болохгүй.

## 4. Оноо хэрхэн тооцогддог вэ

- Хөтөч жинхэнэ дууны даралтыг хэмжиж чаддаггүй тул **"dB" нь харьцангуй түвшин** юм. Laptop нэг газраа, мик нэг байх үед хэн илүү чанга вэ гэдгийг **шударга харьцуулна**.
- **Оноо = хэмжих хугацааны (5 сек) dB-ийн дундаж.** Эхний 0.5 секундийг алгасна (үзэгчдэд хариу үйлдэл хийх хугацаа). Тасралтгүй, урт алга ташилт өндөр оноо авна. Ганц хүн мик рүү ойртож 0.3 секунд хашгирахад дундаж бараг өөрчлөгдөхгүй.
- ⚠ Дунджийг дууны **энергиээр биш, dB-ээр** тооцдог. Энергиээр тооцвол 110 dB нь 70 dB-ээс 10,000 дахин их тул ганц хашгираа дунджийг хөөрөгдөнө.
- **Оргил цэг** (хамгийн өндөр агшин) мөн харагдана.
- **Тэнцвэл:** оргил цэг нь өндөр хүн илүүд тооцогдоно. Тэр нь ч тэнцвэл хоёулаа ижил байр эзэлнэ.
- Хөтчийн автомат дуу намсгалт, чимээ дарагчийг кодоор **унтраасан**.
- Метрийн түвшнүүд: ШИВНЭЭ (30+) → ЧИМЭЭ (55+) → ХАШГИРАА (70+) → ТАЙЗ ДОРГИЛОО (85+) → ЧӨТГӨР СЭРЛЭЭ 💀 (100+)

## 5. 🔒 Хамгаалалт хэрхэн ажилладаг вэ

Энгийнээр хэлбэл: **алдаа гаргаж болох эсвэл буцаах боломжгүй үйлдлүүдийг цоожилсон**. Харин шоуны энгийн алхмууд (бүртгэх, хэмжих, зарлах) цоожгүй, хурдан явагдана.

| Үйлдэл | PIN хэрэгтэй юу |
|---|---|
| Финалист бүртгэх | ❌ Үгүй |
| Анхны хэмжилт хийх | ❌ Үгүй |
| Ялагч зарлах, тэргүүлэгчид харах | ❌ Үгүй |
| **↺ Дахин хэмжих** (оноог солих) | 🔒 Тийм |
| **🗑 Оролцогч устгах** | 🔒 Тийм |
| **⚙ Тохиргоо** (мэдрэмж, тоо, хугацаа, PIN) | 🔒 Тийм |
| **Бүх оноо / бүгдийг устгах** | 🔒 Тийм, мөн "ТИЙМ" дарж баталгаажуулна |

**Алхам алхмаар:**
1. 🔒 тэмдэгтэй товч дарах, эсвэл 💀-г **5 удаа** дарах (эсвэл **Ctrl + Alt + A**) үед PIN асуух цонх гарна.
2. **1031** оруулаад **НЭЭХ** дарна.
3. PIN-ийг **нэг удаа** зөв оруулсны дараа хуудсыг refresh хийх хүртэл дахин асуухгүй. Шоуны үеэр хурдан ажиллахын тулд ингэсэн.
4. Хүмүүс laptop-д хүрэх боломжтой газар үлдээх бол хуудсаа **F5** дарж refresh хийнэ. Ингэхэд дахин цоожлогдоно, харин өгөгдөл устахгүй.

**PIN солих:** тохиргооны **PIN** талбарт шинэ код бичээд **💾 ХАДГАЛАХ** дарна.

> PIN нь зөвхөн санамсаргүй дарахаас хамгаалах **энгийн цоож**. Компьютерт сайн мэдлэгтэй хүн кодыг нь харж чадна. Гэхдээ нэг удаагийн event-д энэ хангалттай.
